# Fontes técnicas aplicadas — Etapa 08

A Etapa 08 foi orientada prioritariamente pelas fontes já autorizadas do Projeto Nexxus:

- Freedesktop Icon Theme Specification;
- Freedesktop Icon Naming Specification;
- Hack upstream / Source Foundry;
- documentação oficial Arch Linux para empacotamento e pacote Hack;
- documentação/pacotes oficiais Debian para empacotamento e Hack;
- `resvg` como validador/rasterizador de build, sem se tornar dependência de runtime do pacote de assets.

A presença dessas referências auxilia o COMO implementar e não altera os requisitos normativos do Nexxus.
