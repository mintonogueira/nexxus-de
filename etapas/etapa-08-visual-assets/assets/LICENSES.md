# Licenças e proveniência — Nexxus Visual Assets

## Assets próprios

Os SVGs simbólicos e wallpapers desta etapa são trabalho original do Projeto Nexxus e seguem a licença do repositório canônico: **GPL-3.0-only**.

Nenhum SVG desta etapa incorpora logotipos, marcas ou ícones proprietários de aplicações externas.

## Hack

A fonte Hack **não é redistribuída neste pacote**. Ela é consumida como dependência nativa da distribuição:

- Arch Linux: `ttf-hack`;
- Debian: `fonts-hack`.

Upstream: Source Foundry Hack.

O projeto Hack registra licenças MIT e Bitstream Vera para as partes pertinentes. O Nexxus não copia os binários da fonte para o repositório; usa os pacotes oficiais das distribuições para manter atualização, integridade e rastreabilidade de licença.

## Ícones de aplicações externas

Ícones declarados por aplicações externas em arquivos `.desktop` mantêm sua identidade, licença e aparência originais. O Nexxus não os recolore. Os ícones próprios desta etapa são usados apenas para elementos internos do desktop e como fallback quando uma aplicação não fornece ícone utilizável.
