# README da Entrega — Etapa 01

O diretório `entrega/` contém os metadados e, após o fechamento material, o snapshot portátil da Etapa 01.

Snapshot padrão: `Nexxus_Etapa01_Core_0.1.0.tar.gz`.

A referência-fonte e o SHA-256 são registrados no manifesto/handoff final para permitir auditoria entre o arquivo entregue e o histórico da `main`.
