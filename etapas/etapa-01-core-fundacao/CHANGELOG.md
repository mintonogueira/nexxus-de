# Changelog

## 0.1.0 — 2026-08-16

- Fundação Rust da Etapa 01 concluída com quatro crates backend-agnostic.
- Registry, lifecycle/rollback, Event Bus, XDG/runtime paths, IPC local, configuração TOML e backend API abstrata implementados.
- Wrappers POSIX Arch/Debian, manifesto, CI, ADRs e documentação incorporados.
- `Cargo.lock` gerado pelo Cargo e validado.
- Build Release, rustfmt, Clippy `-D warnings`, testes e rustdoc aprovados em Arch Linux current e Debian Trixie.
- Pacote nativo e instalação: N/A, pois não existe payload de runtime instalável nesta etapa.
